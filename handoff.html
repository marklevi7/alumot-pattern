01

Dither background · hero preset

WebGL2 Bayer-8 dithered dot field, driven by fBm noise. Sparse, near-empty until a ripple fires. Tap anywhere on the block to fire a ripple. Auto-ripples every 5s.

Deps: three@0.160.0 Preset: hero density 0.0 flowY 0.00 gradientY 0.00 autoRippleMs 5000
Live · tap to ripple
density 0.0 · autoRipple 5s

One shared render loop drives every .dither-bg element on the page — all three CTA blocks (hero, banner, final) run in lock-step against a single THREE.Clock. Instances pause when they scroll off-screen (IntersectionObserver). One instance is skipped silently on devices without webgl2; container keeps its solid bgColor.

HTML
<div class="dither-bg" data-preset="hero"></div>
CSS
.dither-bg { position: absolute; inset: 0; width: 100%; height: 100%; }
.dither-bg canvas { display: block; width: 100% !important; height: 100% !important; }
/* Parent section needs position: relative + overflow: hidden + isolation: isolate.
   DO NOT put z-index on inner .wrap — mix-blend-mode: difference on wordmarks
   above needs the .wrap to stay out of its own stacking context. */
